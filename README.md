# ZUBEEN (ZG) Website

A responsive static website for the ZUBEEN (ZG) independent community project.

## Files
- `index.html` — page content
- `style.css` — responsive black-and-gold styling
- `script.js` — mobile navigation
- `assets/zg-mark.svg` — original text-based ZG emblem

## Before publishing
1. Confirm all project names and permissions.
2. Add only social accounts you control.
3. Keep the token mint address, supply and trading links marked as not available until verified.
4. Review the independent-project disclaimer and obtain legal advice where needed.

## Publish with Cloudflare Pages
1. Open Cloudflare Dashboard → Workers & Pages → Create → Pages → Connect to Git.
2. Select this GitHub repository.
3. Framework preset: None.
4. Build command: leave blank.
5. Build output directory: `/` (or `.` if the dashboard requests it).
6. Deploy.

No build step is required.
